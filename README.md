# SignalBoard

SignalBoard helps builders discover personalized micro-SaaS ideas, turn promising concepts into public validation pages, and measure demand through waitlists.

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS
- Supabase Auth and Postgres
- OpenAI-compatible idea generation API
- Vercel deployment

## Getting started

See `.env.example` for configuration. Install dependencies with `npm install`, then run `npm run dev`.
